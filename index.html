01 / About

A little bit about me

I write the production C++ middleware telematics units run, the Python build and provisioning systems that put firmware on them, and a compiler toolchain for an automotive audio bus.

That includes a cellular voice-readiness feature from algorithm through service and gTest suite, the signing and deploy-artifact generator behind dozens of firmware releases, and production fault debug down to coredumps, register state, and modem traces.

I entered through validation and moved into implementation, systems architecture, and cross-organizational technical design — targeting Senior Software Development Engineer in either embedded or backend systems.
